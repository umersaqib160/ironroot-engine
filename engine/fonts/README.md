# Vendored fonts

Committed on purpose. GitHub's runners do not ship Lora or Lato, and a card that
renders with a fallback font on one machine and the real one on another is not
the same card. Vendoring makes the output identical everywhere.

- **Lato** (SIL Open Font License 1.1) — claim headlines. Humanist, sturdy, plain.
  It suits a buy-it-for-life product better than a geometric or fashionable face.
- **Lora** (SIL Open Font License 1.1) — review quotes. A serif reads as a human
  voice, which is the whole point of a testimonial.

Both licences permit redistribution.
