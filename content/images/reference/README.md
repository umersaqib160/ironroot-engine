# Canonical pan reference photos

## PRIMARY — use this one (Umer, 3 Sep 2026)

**`PRIMARY_pan_studio_2048.jpg`** — 2048x2048 studio shot, whole pan, clean white background.

This is THE reference to attach for image generation, using the subject-placement method in
`automation/QC_process.md` §2.1b: attach this file, describe only the scene, never the pan.
White background and full-object framing make it ideal for placement into a generated scene.

Verified at full resolution, 3 Sep 2026:
- ONE handle — slim, long, gently tapering; elongated teardrop hole at the very tip
- Long, narrow, **splayed Y-fork** with an elongated slot at the body
- **Two dome-head rivets**, polished, on the inner wall
- **Rim: thin plain straight-cut edge — NO rolled lip** (confirmed at 100%)
- Wall and floor: satin, fine brush grain; concentric grain on the floor
- Flared walls, no pour spout, no lid

> **Open point:** in this photo the handle and rivets read noticeably more polished/reflective than the
> satin body, though Umer's description is satin throughout. It is a retouched studio image. Since the
> photo is now the specification, generated content will reproduce whatever this file shows. If the real
> pan reads less polished in ordinary light, a plain phone photo should replace this as PRIMARY.

## The one rule

**Shape and finish are specified by these photographs, never by adjectives.** The July 2026 defects were
caused by prose ("droplet/bulb profile, widest near the end", "never a slim straight handle") overriding
the attached photo. Prose says what to check; it never says what the pan looks like.
See `../../../automation/qc_regression/`.
